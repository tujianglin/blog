# tailwindcss 生态

- [tailwindcss](https://tailwindcss.com/) 官方文档

## 使用

```sh
 npx tailwindcss init -p
```
`将生成的文件后缀改成mjs`

```js
/** @type {import('tailwindcss').Config} */
export default {
  content: ['./index.html', './src/**/*.{js,ts,jsx,tsx}'],
  theme: {
    extend: {},
  },
  plugins: [
    // 自定义 class
    function ({ addComponents }) {
      addComponents({
        '.btn': { padding: '1rem 2rem' },
      })
    },
  ],
}
```
